## Install into another agent

```bash
git clone https://github.com/joecastelino/jay-skill-pack.git
cp -r jay-skill-pack/skills/* ~/.hermes/profiles/<agent>/skills/
```

Secrets (passwords, app passwords, tokens) are redacted with `<PLACEHOLDER>` markers — grep for `REDACTED` / `<TEKION_PASSWORD>` / `<GMAIL_APP_PASSWORD>` and supply your own.
